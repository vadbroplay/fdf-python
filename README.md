# FdF — визуализатор карты высот

Учебный проект на Python для отображения каркасной трёхмерной модели карты высот в изометрической проекции.

## Возможности

- Загрузка карт высот из файлов `.fdf`.
- Проверка корректности формата входных файлов.
- Отображение карты в изометрической проекции.
- Раскраска точек и рёбер в зависимости от высоты.
- Поддержка пользовательских цветов в файлах карты.
- Приближение и отдаление колёсиком мыши.
- Перемещение карты мышью.
- Изменение масштаба высот и поворот карты с клавиатуры.
- Автоматические тесты и статический анализ кода.

## Требования

- Python 3.12 или новее.
- Tkinter, доступный в установленной сборке Python.

## Установка

Клонируйте репозиторий и перейдите в каталог проекта:

```bash
git clone https://github.com/vadbroplay/fdf-python
cd fdf-python
```

Создайте виртуальное окружение:

```bash
python -m venv .venv
```

Активируйте его в Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

Установите проект и инструменты разработки:

```bash
python -m pip install -e ".[dev]"
```

## Запуск

Запустите программу, указав путь к файлу карты:

```bash
python main.py maps/elem.fdf
```

В проекте также имеется плоская тестовая карта:

```bash
python main.py maps/flat.fdf
```

## Управление

- **Колёсико мыши** — приближение и отдаление.
- **Левая кнопка мыши + перемещение** — перемещение карты.
- **A / D** — поворот карты.
- **V** — переключение вида сверху.
- **Стрелки клавиатуры** — перемещение карты.
- **+ / −** — изменение вертикального масштаба.
- **Esc** — закрытие приложения.

## Формат файлов `.fdf`

Файл содержит строки целых чисел, разделённых пробелами. Каждое число обозначает высоту соответствующей точки. Все строки должны иметь одинаковое количество значений.

Пример:

```text
0 0 0
0 5 0
0 0 0
```

Также могут использоваться пользовательские цвета в формате `,0xRRGGBB`, например:

```text
0 0,0xFF0000 0
0 5 0
0 0 0
```
